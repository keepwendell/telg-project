# TELG 产品定义（Product Brief）

> 版本：2026-09-18 · 早期定位"面向技术研发的参数化生成器"已随产品演进泛化，本文为当前口径。
> **定位一句话**：沉浸式场景听力素材生成器——描述一个真实场景，生成一套"像真实发生一样"的双语听力素材。

## 1. 背景与要解决的问题

职场人、学生、求职者、管理者等在学习与工作中需要听懂大量英文内容，但现有英语学习材料普遍存在：

- **内容不相关**：通用主题对真实场景（技术评审、面试、客户沟通、课堂讨论）帮助有限；
- **场景不真实**：缺乏真实语境，学完无法直接迁移到要面对的场合；
- **难度不可控**：无法按个人水平精确调节（"专业"与"复杂"常被混为一谈）；
- **缺少针对性**：不覆盖岗位真实场景（如 Design Review、Technical Interview、跨部门评审）。

产品要解决的核心问题：**给定一个真实场景，能否生成"真实、自然、可信、适合听力训练"的双语内容。**

## 2. 核心定位

**不是**：固定主题的英语听力 Demo、一个"LLM + TTS 的英语学习网站"。

**是**：一个场景化的听力素材生成引擎（Technical English Listening Generator，领域可扩展）。

用户描述一个场景并配置几个核心参数（场景语境 / 对话形态 / 领域 / 角色 / 时长 / 词汇专业度 / 句式复杂度），系统自动完成：

```
场景描述 + 参数配置
  → LLM 生成双语素材（场景背景 / 对话 / 词汇 / 听力题 / 句型，一次产出）
  → 结构与质量校验（分区重试）
  → 逐句 TTS
  → 音频拼接 + 时间轴回填
  → 播放器（中英对照 / 逐句高亮 / 盲听）
  → 讲义（Handout）导出
```

最终输出**一套完整的听力学习材料**，而不仅仅是一段音频。

## 3. 产品差异化：Technical Grounding（技术知识锚定）

LLM 生成内容时**不能只考虑英语语言质量，还要考虑真实的工程背景**。

示例：Topic = Tire Burst Stability Control，生成对话应自然涉及：

`rolling resistance / cornering stiffness / yaw moment / yaw rate / sideslip / torque vectoring / wheel load / vehicle dynamics / stability control`

同时讲义应解释真实工程原理：

- Engineering Background：爆胎后滚动阻力、纵向/侧向力特性、有效滚动半径变化；前轮爆胎因左右受力不对称产生横摆力矩；
- Technical Principle：控制器根据爆胎位置修正车辆动力学参数，通过 Torque Vectoring 产生补偿横摆力矩，维持期望横摆率与侧滑状态。

**核心价值一句话：用真实技术知识作为内容背景，用英语作为训练载体。**

## 4. 目标用户

- **准备英文面试的人**：生成目标岗位、目标领域、目标风格的面试对话；
- **需要开英文会议的职场人**：跨部门评审、客户沟通、项目例会；
- **想积累专业英语的人**：围绕自己领域的术语、表达与讨论方式生成素材；
- **学生 / 求职者 / 管理者**：课堂讨论、答辩、求职面谈、团队沟通；
- 技术研发人员仍是最典型场景之一（汽车 / 控制算法 / 软件工程 / AI 等），但**技术只是支持的领域之一，不是默认**。

## 5. 工作原则

- 简单优先、MVP 优先；
- Provider 可插拔（LLM / TTS 均不修改业务逻辑即可切换）；
- 数据结构稳定（Generation Artifact 作为 LLM、TTS、播放器、讲义之间的共同数据源）；
- 字段语义优先（difficulty=词汇专业度，depth=句式复杂度，场景语境优先级最高）；
- 前后端解耦；
- 避免过度工程化。

## 6. 未来方向

- ✅ 已实现：盲听模式（正常 / 盲听切换，文本模糊先听后看）；
- **个性化难度**：根据历史表现自动调整 Level；
- **错题/薄弱词汇**：记录易错词，下一次生成优先覆盖；
- **个人词库**：用户建立 My Vocabulary，LLM 生成时优先使用；
- **技术领域模板**：Automotive / Software / AI 分层目录；
- **多语言素材**（日语优先）、词级时间戳跟读、环境噪音叠加。
