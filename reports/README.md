# 问题与报告（Reports）

> 版本：2026-09-16 · 用途：按「问题或报告名」建文件夹，记录问题分析、解决对策与修复完成情况。问题先在 reports 立档 → 修复 → 验证结论回写 → 长期取舍提炼进 docs。

## 规范

- 文件夹命名：报告名（必要时 `YYMMDD-报告名`），内容文档纯中文。
- 结构（复杂问题三件套，简单问题可合并）：
  - `问题分析.md` — 现象、复现步骤、根因
  - `解决对策.md` — 修复方案、改动文件、取舍
  - `修复验证.md` — 验证方式、结果、遗留问题（修复后追加）
- 状态在 [README](#问题状态) 表中维护：`进行中 → 已修复 → 已关闭`。
