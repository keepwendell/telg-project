## 会话要点

### 需求与决策

- **体验细化 6 处**（`frontend/index.html`）：
  1. 生成等待界面提示：`#gen-waiting-note` 提示行（`gen.waiting` / `gen.switchHint` 中英文案）；
  2. 生成中切走不抢焦点：`state.genNavGuard = { navigated }` 守卫——`runGenerate` 建立，`loadMaterial` / `jumpToBookmark` 置位；完成块仅当「导航过且当前素材非新素材」才不抢焦点（否则照常 `playArtifact` 选中新素材）；
  3. 播放列表体验：连播跳过未合成素材时 toast「已跳过未合成音频的素材」（`pl.skipUnsynth`）；`loadMaterial` 在列表上下文自动设置 `state.activePlaylist`；
  4. 句子收藏优化：`toggleBookmark` 条目补 `text_zh`，`renderBookmarks` 英文下行加中文行，旧数据兼容。
- **剧情引子（overview）标准（用户定稿）**：① 不得剧透 Quiz 关键问题（问题/答案/考察点关键词均不得出现）；② 播放器对话区顶部（transcript 之前）常显、不折叠；③ 双语（text_en + text_zh），跟随翻译按键，豁免盲听（不模糊不隐藏）。
- **结构化默认命名**：用户提供《Scenear 素材默认命名规范 v1.0》**仅作参考**，不要求恢复默认名；重名去重定为 `(1)` 后缀（否决 `#2` 方案）；命名结合 LLM 能力——主名称优先用 LLM 同次调用产出的 `title`（`meta.llm_title`），不合格回退规则命名 `extractTopicFallback`；名称语言随场景语境（`localeOf`），不随界面语言切换。
- **重名检查**：素材与播放列表重命名均加重名检查（大小写不敏感、排除自身），覆盖列表重命名 / 头部重命名 / 发布弹窗 / 播放列表创建与重命名共 5 个入口。
- **release 前审视（本轮）**：核心链路健康，门禁见下。
