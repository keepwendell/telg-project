# 会话要点：侧栏信息架构重构与 Prompt 调优

> 日期：2026-09-16 · 主题：主界面交互可用性迭代（侧栏手风琴 / All Materials / 删除弹窗 / Toast / Prompt 重构）

## 会话要点

### 需求与决策

- **Toast 体验**：成功 / 错误 / 警告使用区分图标（check / x / triangle / info）；统一展示时长 2600ms（否决分类型时长方案）；鼠标悬停时 Toast 不消失。
- **主界面精简**：删除今日听力面板的 Speed 1.0x 占位；引擎徽章 hover 显示精简状态（`MMDD HHMMSS` + LLM/TTS 可用性与原因）；Details 按钮仅在详情面板有内容时显示；删除左右侧栏独立折叠键，改为 Queue 按钮绑定左栏折叠、Details 按钮绑定右栏展开/收起。
- **自检可读性**：新增 `friendlyErr` 中英错误映射，后端未启动 / 无 Key 等常见错误转为简短人话，未知错误超长截断。
- **详情面板**：默认收起；仅当素材有内容时详情按钮才出现。
- **素材区**：字体调节同时作用于英文与中文行；无素材时 btn-font 禁用；空素材时主区显示空态卡片（波形图标 + 引导文案 + 生成按钮）。
- **搜索移除**：删除左侧搜索框（search-input、`/` 快捷键、query 过滤），保留领域筛选 filter-tags；新建素材入口迁至原搜索栏位置。
- **新建素材入口**：经历「虚线两行 → 顶部占位样式 → 精简」，最终为「闪电图标 + New Material」单行按钮（原搜索框位置）。
- **播放列表手风琴化**：点击播放列表在其下方内联展开素材（pl-item），互斥切换；activePlaylist 语义保留，继续驱动 Queue 连播。
- **删除 My Materials 栏目**：新增 "All Materials" 手风琴项（PLAYLISTS 首位），展开显示全部素材（保留添加/重命名/删除操作与领域筛选）；My Materials 独立区删除；Queue 连播在 All Materials 展开时按全部素材顺序可用。
- **空列表文案精简**：`No materials yet` / `No materials in this playlist`（中英同步）。
- **删除确认弹窗美化**：动态标题（Delete material? / Delete playlist?，中英）；52px 红渐变图标 + 光晕；背景虚化（backdrop blur）；说明文案从 "My Materials" 口径更新为 "All Materials / 素材库" 口径。
- **Prompt 重构**：LLM system prompt 静态化（不再按请求替换难度定义）；user prompt 改为需求简报式（讲清"为什么生成"，而非"填什么字段"）；难度定义可执行化（DIFFICULTY_DEFS）；max_tokens 按目标字数推导；新增 `POST /api/v1/config/prompt-preview`（纯拼装、不调 LLM）+ 设置页 "LLM Prompt Preview" 面板。
- **修复**：语料生成后"编辑语料 / 设置音色并合成"按钮不可用；生成失败 Toast 出现一大串 HTML 错误原文。
