# 会话要点：Refine 弹窗对齐 Demo 与前后端链路修复

> 日期：2026-09-18 · 主题：调整语料弹窗按 refine_demo 对齐（暗色为准 + 亮色适配）、ⓘ 悬停修复、生成方向「发散」、前后端一致性审查与修复（refine 结构恢复 / directions 消费）

## 会话要点

### 需求与决策（UI）

- **Refine 弹窗整体对齐 refine_demo**：暗色以 demo 为准（弹窗底 `#0c0e12`、seg 容器 `#12151a`、输入框 `#0a0d11`、圆角 16、宽 464→520），亮色按同层级适配（`#f4f4f6` / `#f0f0f3` / 白底）；字段 = 标签 + ⓘ + 标签行 inline hint（蓝色名称 + 灰色括号解释）；seg 为填充式分段滑组（选中 `--primary` 填充，深色浅蓝底深字 / 亮色深蓝底白字）；底部「取消 / 调整并重新生成」同高 40px、间距 18px；去掉弹窗内多余 "Corpus Text" 段头；标题文案改为「调整语料 / Edit Corpus」。
- **ⓘ 悬停无提示（修复）**：根因是 tooltip 的 mouseover/mouseout 监听只匹配 `#gen-panel [data-tip]`，且气泡挂在 gen-panel 内（refine 打开时 gen-panel 隐藏）。修复：监听选择器扩展为 `#gen-panel, #adjust-modal`，气泡 `#telg-tip` 挂 body，样式改为主题适配（`--surface-high` / `--on-surface`）。
- **生成方向第四项「换向 → 发散」**：按钮短词与 hint 名称/描述（`refine.dirAngle` / `dirAngleDesc` / `tipDir`）中英同步；demo 同步修改。
- **新建素材弹窗输出参数改单列**：输出参数区从 2 列网格改为单列 3 行（对话时长 / 词汇专业度 / 句式复杂度各一行），英文长标签不再挤压；字段标签统一 `white-space:nowrap` 防换行。

### 前后端一致性审查与修复（业务）

审查结论：发现 3 处前后端不一致，均已修复。

- **① Refine 生成方向完全失效（双端断裂）**：前端 `refineGenerate` 读取已删除的 `input[name="refine-dir"]:checked`（UI 改 seg 按钮后失效）→ `directions` 恒为空；后端 prompt 从未消费 `advanced.directions`。修复：前端改读 `#refine-dir .seg-item.active`；后端新增 `DIRECTION_DEFS`（rephrase/expand/narrow/re-angle → 中文生成指令），生成约束追加「生成方向」行。
- **② Refine 丢失素材对话结构（严重）**：`paramsFromArt` 未传 `format / asymmetric / roles / roleSelection / context`，后端默认按 discussion + 「通用专业场景」重生成，solo/dialogue 素材被破坏、角色退化为 Engineer N。修复：后端生成时把 `format / asymmetric / roles`（solo `{speaker}`、dialogue `{a,b}` 或 `{lead,respond}`、discussion `{candidates,speakerCount}`）持久化进 `meta`；前端 `paramsFromArt` 从 meta 恢复全部 v2 结构字段（含 context）。
- **③ 词汇密度键名错位**：后端存 `meta.speechRate`，前端读 `m.vocabDensity` 恒 28。修复：前端改读 `m.speechRate ?? m.vocabDensity`。

### 未破坏的既有链路（确认）

- **语料完整性**：LLM System prompt 输出契约未动，仍强制 background（中英）/ speakers / dialogue（text_en + text_zh 双语）/ vocabulary / listening_questions（含中文）/ core_sentence_patterns（含中文）。
- **角色 ↔ TTS 联动**：synthesize 仍按 `meta.speakers` 逐角色分配音色（lead → 第一音色、respond → 第二、多人循环）；本轮仅新增 meta.roles 存储，未触碰 speakers 生成与保存。
