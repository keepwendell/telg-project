# 260919 · v0.2.0 发布

## 会话要点

### 需求
- 将版本号提升到 **0.2.0**，提交入库并创建 GitHub Release。

### 本版累计改动
- **TTS 合成失败修复**：修复 `synthesize_stream` 中 `body` 变量作用域导致的 `UnboundLocalError`（合成第一步即崩）；`synthesize_stream` 总时长/句间静音/排序/残留清理/seq/错误归类 6 处修正；新增单句合成 3 次静默重试。
- **前端 SSE 错误处理**：`synthesizeStream` 保证失败一定 `reject`、成功一定 `resolve`，修掉「Cannot read properties of null (reading 'audio_url')」。
- **浅色主题**：语料/TTS 进度条颜色改用主题 token；子步骤图标块减淡。
- **置顶头部重构**：`transcript-head` 改为固定区 + `transcript-scroll` 独立滚动容器，彻底消除滚动时 transcript 漏字。
- **详情面板联动**：生成/合成时自动收起右侧详情面板并禁用「详情」按钮，任务结束后恢复；refine/TTS 弹窗不再改动三步进度条，仅「发布」更新。
- **MD 导出增强**：导出文件按素材标题命名，新增「剧情概述」「角色」两节，全篇中英对照。
- **动效修复**：`ui.js` 时长单位由毫秒改为秒（Motion 的 `duration`/`delay` 以秒计），修复字体菜单、倍速菜单淡入卡在 opacity≈0 而不可见的问题。
- **版本统一**：前端 `index.html` / `state.js`、后端 `main.py`、`package.json` 统一为 `0.2.0`。

### 验证
- 无头浏览器实测：TTS 合成成功、时长与时间轴正确、`/synthesize/stream` 正常推送 complete；字体菜单可见且点选生效；详情面板随任务收起/恢复；置顶头部滚动不漏字。
