# 对话要点日志（Changelog）

> 版本：2026-09-16 · 用途：记录每次协作会话的需求要点、决策、改动与验证结果。**只记流水账，不触发 commit**；提交由用户点名时统一执行，commit body 从本目录要点合并生成。

## 记录规范

- 一个会话一个文件：`YYMMDD-会话主题.md`（日期为会话发生日，两位年）。
- 文件结构：会话要点（需求/决策/改动/验证/待确认）→ 拟定 commit。
- 与其它目录边界：
  - `docs/` 承载知识（为什么/怎么搭），不记录过程；
  - `reports/` 承载问题→方案（问题分析/对策/修复验证）；
  - 本目录仅记录「这次会话做了什么、定了什么」。
- changelog 满 30 个文件时归档到 `YYYY/` 子目录。
